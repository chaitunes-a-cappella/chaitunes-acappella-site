# ChaiTunes A Cappella Website

This is the official website for **ChaiTunes A Cappella**, Emory University’s Jewish a cappella group.  
It acts as a central digital home for our music, performances, and group identity.

## Project Motivation

The previous ChaiTunes website was outdated and didn’t showcase the group as current or actively evolving.

This project was created to:
- Give the group full ownership of its digital presence  
- Build a modern, maintainable platform for current and future members  
- Create a centralized space for music, media, and group information  
- Make updates and content changes accessible without relying on third-party site builders  

The focus wasn’t just redesigning — it was creating something sustainable and technically clean.

## What Went Into Building It

This project emphasized structure, maintainability, and long-term usability.

Major areas of focus included:
- Designing a clean and scalable layout system  
- Creating a responsive UI for desktop and mobile  
- Structuring content so it can be easily updated as the group evolves  
- Separating frontend logic from data management  
- Implementing a functional contact system without a dedicated backend server  
- Thinking about how future members without deep technical backgrounds could maintain the site  

A lot of time went into balancing good design with simplicity and sustainability.

## Tech Stack

- **Frontend**: Tailwind CSS  
- **Backend / Database**: Supabase  
- **Hosting**: Vercel  
- **Email Services**: EmailJS  
- **Version Control**: Git & GitHub  

Tailwind CSS allowed for fast iteration on UI design while maintaining consistency and flexibility.  
Supabase was used for managing structured content, backend services, and long-term scalability.  
EmailJS enabled a backend-free contact form system to allow users to directly communicate with the group without server-side email handling.

## Development Process

This was a collaborative and iterative build process.

Some key elements of the workflow included:
- Translating group goals and identity into a consistent visual style  
- Building reusable layout sections  
- Integrating Supabase for content storage and data handling  
- Implementing EmailJS for contact form functionality  
- Iterating based on feedback from group leadership  
- Focusing on mobile responsiveness from the start  
- Prioritizing clarity and ease of future maintenance over overengineering  

The goal was to make something that not only looks good but is easy for future boards to own technically.
